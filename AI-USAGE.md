# Использование ИИ

ИИ применялся как ускоритель реализации и reviewer, но решения проверялись по домену и документации платформ.

| Предложение | Почему отклонено | Решение |
|---|---|---|
| `Math.Round(value, 2)` | default midpoint-to-even не закрепляет бухгалтерское правило | `MidpointRounding.AwayFromZero` в одном `Money` |
| Считать ставку `$lookup`-ом в каждом отчёте | дорогой join на миллионах строк | денормализовать applied rate/amount и пересчитывать открытые записи |
| Хранить `isOvertime` в записи | флаг меняется при добавлении/удалении соседней записи | вычислять по дневной сумме на чтении |
| Отправлять `toLocaleDateString()` | locale и timezone делают контракт неоднозначным | ISO `YYYY-MM-DD` и `DateOnly` |
| Считать итоги в React | пагинация делает итог страницы неверным | отдельная Mongo aggregation по тому же фильтру |
| Добавить SignalR сразу | увеличивает объём без влияния на приёмочные правила | оставить явной точкой развития после correctness |

Перед коммитами выполняются компиляция, typecheck, lint, tests и форматирование. Semgrep отдельно ищет характерные регрессии и опасные шаблоны, независимо от происхождения кода.
