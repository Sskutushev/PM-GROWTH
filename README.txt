ТЕСТОВОЕ ЗАДАНИЕ — FULLSTACK-РАЗРАБОТЧИК (.NET + MongoDB + React/TypeScript)

Что в архиве
------------

  test-task.pdf                          само задание, читать целиком
  code-review/TimesheetReportHandler.cs  файл для части 1 (code review)
  code-review/TimeEntriesPage.tsx        файл для части 1 (code review)
  test-task.html                         та же версия задания для браузера

С чего начать
-------------

1. Прочитайте test-task.pdf целиком, включая раздел «Приёмочные проверки»:
   там указаны конкретные цифры, по которым мы будем проверять результат.

2. Часть 1 — разбор двух файлов из папки code-review. Занимает 1–1,5 часа,
   результат оформляется в REVIEW.md.

3. Часть 2 — небольшой проект на .NET + MongoDB + React, 4–6 часов.

Сроки и объём
-------------

Ориентировочно 6–8 часов работы, сдать в течение 5 календарных дней с момента
получения задания.

Важное
------

Вопросы приветствуются — задавайте их ответным письмом на любом этапе. В задании
намеренно оставлено несколько неоднозначных мест; уточняющий вопрос улучшает
оценку, а не ухудшает её.

ИИ-ассистенты (Claude Code, Copilot, Cursor) разрешены. Условие одно: на разборе
вы объясняете любую строку своего кода.

Что прислать
------------

Ссылку на репозиторий (GitHub или GitLab) с README.md, REVIEW.md, NOTES.md,
кодом и тестами. Подробности — в конце test-task.pdf.
